# 环城导航

> 题目标识：`Pre_ring_distance`

## 1 题目简介

一条环形轨道共有 **16 个站点**，编号为 `0` 到 `15`。给定起点和终点，请设计组合逻辑，判断从起点沿环形轨道到终点的最短距离和方向。

## 2 信号定义

模块名：`main`

| 信号名 | 方向 | 描述 |
| --- | :---: | --- |
| `pos[7:0]` | `I` | `pos[7:4]` 为起点 `start`，`pos[3:0]` 为终点 `target`，取值范围均为 `0` 到 `15` |
| `result[5:0]` | `O` | `result[3:0]` 为最短距离，`result[5:4]` 为方向编码 |

## 3 方向编码

| `result[5:4]` | 含义 |
| :---: | --- |
| `00` | 起点与终点相同 |
| `01` | 沿顺时针方向行进 |
| `10` | 沿逆时针方向行进 |
| `11` | 顺时针距离与逆时针距离相等 |

环上站点编号按顺时针方向递增，站点 `15` 的下一站为 `0`。当顺时针距离与逆时针距离相等且起点与终点不同时，距离为 `8`。

![环形站点与方向约定](assets/ring-navigation.png)

## 4 示例

输入：

```verilog
pos = 8'h2E;
```

此时起点为 `2`，终点为 `14`。顺时针需要经过 `12` 站，逆时针需要经过 `4` 站，因此输出为：

```verilog
result = 6'b10_0100;
```

方向编码 `10` 表示逆时针，距离字段 `0100` 表示 `4`。

## 5 提交要求

1. 文件内模块名必须为 `main`。
2. 必须使用组合逻辑实现。
3. 模块外观必须与下图一致，否则可能造成评测错误。
4. 输入端口 `pos[7:0]` 和输出端口 `result[5:0]` 的名称、方向、位宽及上下顺序必须与信号定义一致。
