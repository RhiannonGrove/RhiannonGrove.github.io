# 简易注释过滤器

> 题目标识：`P1_comment_filter`

## 1 题目描述

程序中常用 `/* ... */` 表示注释。请使用 Verilog 实现一个简易注释过滤器，串行接收字符，并实时输出从上次复位以来，已读入文本去掉注释后剩余的字符数。

## 2 过滤规则

字符 `/` 和 `*` 的 ASCII 编码分别为：

```text
'/' = 8'h2F
'*' = 8'h2A
```

除这两个字符外，所有 8 位输入值均可视为合法 ASCII 字符。

输入按照从左到右的顺序处理：

1. 在注释外，连续出现的两个字符 `/*` 表示注释开始。
2. 进入注释后，随后第一次出现的 `*/` 表示注释结束。
3. 不支持注释嵌套。在注释内部不再识别新的开始标记，只查找结束标记。
4. 注释开始标记、结束标记及二者之间的所有字符均不计入结果。
5. 本题只识别块注释，不识别 `//` 行注释；也不对引号或转义字符进行特殊处理。

例如：

- `/**/` 是完整注释，四个字符均不计数。
- `/*/` 尚未出现完整的结束标记，因此读完后仍处于注释状态。

### 2.1 未确定的 `/` 如何计数

统计结果必须根据当前已经读入的字符确定，不能等待后续字符：

- 在注释外读到 `/` 时，先将它作为普通字符计数。
- 如果下一个字符是 `*`，则刚才的 `/` 与本次的 `*` 共同组成注释开始标记。此时应扣除此前已计数的 `/`，本次的 `*` 不计数，并进入注释状态。
- 进入注释后，在找到结束标记 `*/` 之前，读入的字符均不增加计数。

设从上次复位到最近一次时钟上升沿已经读入的文本，按照上述规则处理后得到的非注释字符数为 `N`，则输出为：

```text
count = N mod 256
```

即输出仅保留低 8 位。例如，读到 `260` 个非注释字符时，输出为 `4`。

## 3 模块规格

模块名：`comment_filter`

本题要求使用 **Moore 型状态机**。计数值也是状态的一部分，输出 `count` 只能由当前已保存的状态决定。

输入字符 `char` 的变化不会立即改变输出；只有在时钟上升沿采样输入并更新状态后，`count` 才会更新。

| 信号名 | 方向 | 位宽 | 描述 |
| --- | :---: | :---: | --- |
| `clk` | 输入 `I` | 1 bit | 时钟信号，在上升沿采样输入并更新状态 |
| `reset` | 输入 `I` | 1 bit | 同步复位信号，高电平有效 |
| `char[7:0]` | 输入 `I` | 8 bit | 当前输入字符的编码 |
| `count[7:0]` | 输出 `O` | 8 bit | 从上次复位到当前采样的有效字符数，仅保留低 8 位 |

### 3.1 时钟上升沿处理优先级

每个时钟上升沿按照以下优先级处理：

1. 若 `reset = 1`，清空此前的输入记录和内部状态，将 `count` 置为 `0`，且本次不接收 `char` 中的字符。复位后默认处于注释外。
2. 否则，接收 `char` 中的一个字符，并按照过滤规则更新内部状态和 `count`。

开始输入字符前，应先进行同步复位。

## 4 输入输出示例

先进行同步复位，随后保持 `reset = 0`，依次输入：

```text
ab/*xy*/cd
```

![输入输出波形示例](assets/example-waveform.png)

处理过程如下：

| 输入字符 | 说明 | `count` |
| :---: | --- | :---: |
| `a` | 普通字符 | 1 |
| `b` | 普通字符 | 2 |
| `/` | 暂时作为普通字符计数 | 3 |
| `*` | 与前一个 `/` 组成开始标记，扣除 `/` | 2 |
| `x` | 位于注释内，不计数 | 2 |
| `y` | 位于注释内，不计数 | 2 |
| `*` | 可能是结束标记的第一字符，不计数 | 2 |
| `/` | 与前一个 `*` 组成结束标记，不计数 | 2 |
| `c` | 普通字符 | 3 |
| `d` | 普通字符 | 4 |

因此，最终输出为：

```text
count = 4
```
