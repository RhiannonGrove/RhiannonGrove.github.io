# 公共预约时间

> 题目标识：`P0_reservation_time`

## 1 题目描述

三位同学准备预约同一天的讨论室，每人提出一个时间约束：预约时间不能早于某个时刻，或者不能晚于某个时刻。

请使用 Logisim 设计一个**组合逻辑电路**，求出同时满足三人要求的公共时间段，并输出该时间段的下界和上界。

## 2 功能说明

讨论室当天的可预约时间范围为闭区间 `[0, 24]`。其中，`24` 表示当天结束的时刻，不与 `0` 视为同一时刻。本题不涉及跨天预约。

每个约束由一个 5 位无符号数 `time` 和一个 1 位方向信号 `dir` 表示。设可预约时刻为 `t`，编码规则如下：

| `dir` | 约束 | 含义 |
| :---: | :---: | --- |
| `0` | `t >= time` | 不早于指定时刻 |
| `1` | `t <= time` | 不晚于指定时刻 |

三个约束分别通过 `time1`、`dir1`、`time2`、`dir2`、`time3`、`dir3` 给出，且必须同时满足。三个约束没有优先级，输入顺序不影响结果。

输出 `lower` 和 `upper`，表示所有满足约束的时刻构成的完整闭区间：

```text
[lower, upper]
```

- `lower` 是公共时间段的下界。
- `upper` 是公共时间段的上界。
- 两个端点均包含在公共时间段内。
- 如果三个约束中没有“不早于”的要求，则下界默认取 `0`。
- 如果三个约束中没有“不晚于”的要求，则上界默认取 `24`。

## 3 输入保证

- `time1`、`time2`、`time3` 均为 `0` 至 `24` 的整数，不会输入 `25` 至 `31`。
- 不同约束中的时间可以相同。
- 三个约束与 `[0, 24]` 的交集一定具有正长度，即：

```text
0 <= lower < upper <= 24
```

- 不需要处理交集为空或仅包含一个时刻的情况。

## 4 输入输出

| 名称 | 功能 | 位宽 | 方向 |
| --- | --- | :---: | :---: |
| `time1` | 第一个约束的时刻 | 5 | 输入 `I` |
| `dir1` | 第一个约束的方向 | 1 | 输入 `I` |
| `time2` | 第二个约束的时刻 | 5 | 输入 `I` |
| `dir2` | 第二个约束的方向 | 1 | 输入 `I` |
| `time3` | 第三个约束的时刻 | 5 | 输入 `I` |
| `dir3` | 第三个约束的方向 | 1 | 输入 `I` |
| `lower` | 公共时间段的下界 | 5 | 输出 `O` |
| `upper` | 公共时间段的上界 | 5 | 输出 `O` |

所有时间输入和输出均按无符号数解释。

## 5 示例

设三位同学的约束分别为：

```text
t >= 8
t <= 20
t >= 12
```

使用十进制表示时，输入输出如下：

| 名称 | 值 |
| --- | :---: |
| `time1` | `8` |
| `dir1` | `0` |
| `time2` | `20` |
| `dir2` | `1` |
| `time3` | `12` |
| `dir3` | `0` |
| `lower` | `12` |
| `upper` | `20` |

三个约束对应的区间交集为：

```text
[8, 24] ∩ [0, 20] ∩ [12, 24] = [12, 20]
```

因此输出：

```text
lower = 12
upper = 20
```

另一个例子：若三个约束分别为 `t <= 6`、`t <= 20`、`t <= 12`，由于没有“不早于”的要求，下界取默认值 `0`，因此输出：

```text
lower = 0
upper = 6
```

## 7 思路

1.根据 `dir` 的取值，通过多路选择器对三者的`upper`和`lower`进行定义。

2.分别比较三者的`upper` 、`lower`，确定最后输出。
