# 分段饱和加法

> 题目标识：`Pre_sat_add`

## 1 简介

将两个 32 位输入分别看成四个互不相关的 8 位无符号数，并对对应字节分别执行饱和加法。

## 2 功能要求

对每个字节位置分别执行无符号加法，并独立饱和。任何字节产生的进位都不得影响相邻字节。

对于 `i = 0, 1, 2, 3`：

```text
out_i = min(a_i + b_i, 255)
```

其中：

```text
a_i   = a[8*i+7 : 8*i]
b_i   = b[8*i+7 : 8*i]
out_i = out[8*i+7 : 8*i]
```

每个字节的计算彼此独立：

| 字节编号 | 输入 `a` | 输入 `b` | 输出 `out` |
| :---: | :---: | :---: | :---: |
| 0 | `a[7:0]` | `b[7:0]` | `out[7:0]` |
| 1 | `a[15:8]` | `b[15:8]` | `out[15:8]` |
| 2 | `a[23:16]` | `b[23:16]` | `out[23:16]` |
| 3 | `a[31:24]` | `b[31:24]` | `out[31:24]` |

若某一字节的加法结果大于 `8'hFF`，则该字节的输出固定为 `8'hFF`。

## 3 模块规格

模块名：`sat_add`

| 信号名 | 方向 | 位宽 | 描述 |
| --- | :---: | :---: | --- |
| `a[31:0]` | 输入 `I` | 32 bit | 四个 8 位无符号加数 |
| `b[31:0]` | 输入 `I` | 32 bit | 四个 8 位无符号加数 |
| `out[31:0]` | 输出 `O` | 32 bit | 四个独立的饱和加法结果 |

## 4 输入输出示例

输入：

```verilog
a = 32'h01FF807F;
b = 32'h02018081;
```

输出：

```verilog
out = 32'h03FFFFFF;
```

逐字节计算如下：

| 字节 | 加法 | 输出 |
| :---: | --- | :---: |
| `[7:0]` | `8'h7F + 8'h81 = 9'h100`，发生溢出 | `8'hFF` |
| `[15:8]` | `8'h80 + 8'h80 = 9'h100`，发生溢出 | `8'hFF` |
| `[23:16]` | `8'hFF + 8'h01 = 9'h100`，发生溢出 | `8'hFF` |
| `[31:24]` | `8'h01 + 8'h02 = 8'h03` | `8'h03` |

最低字节中的进位不会传递到相邻字节；四个字节始终独立计算。

## 5 提交要求

1. 使用 Verilog HDL。
2. 提交文件中的模块名必须为 `sat_add`。
3. 端口名称、方向和位宽必须与模块规格完全一致。
4. 设计必须为组合逻辑，不得依赖时钟或初始值。
5. 模块内不得包含 `$display`、`$monitor` 等仿真输出语句。
