## 路径

1. 打开 Github 仓库
2. 进入 source -> _posts
3. 右上角 Add file -> Create new file

## markdown文档编写规则

### 1.文章开头信息

每篇文章必须以这段信息开头：

```
---
title:文章标题
date:2026-01-01 00:00:00
tags:
 - 随笔
 - 阅读
---
```

注意不要忘记 `---` 。

### 2.标题

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

文章本身已经有大标题，正文一般从 `## 二级标题` 开始。
`#` 后面必须留一个空格。

### 3.段落和换行

不同段落之间要空一行：

```
这是第一段文字。

这是第二段文字。
```

只按一次回车，通常不会产生新段落。

### 4.粗体和斜体

```
这是 **粗体文字**。

这是 *斜体文字*。

这是 ***粗斜体文字***。
```

显示效果：
这是 **粗体文字** ，这是 *斜体文字* 。

### 5.列表

无序列表：

```
- 第一项
- 第二项
- 第三项
```

有序列表：

```
1. 第一步
2. 第二步
3. 第三步
```

嵌套列表需要缩进：

```
- 阅读
  - 小说
  - 散文
- 生活
  - 旅行
  - 日常
```

### 6.引用

```
> 愿每一篇记录，都能成为日后回望时的一点光。
```

多段引用：

```
> 这是第一段引用。
>
> 这是第二段引用。
```

### 7.链接

```
[链接显示的文字](https://example.com)
```

例如：

```
访问我的 [GitHub主页](https://github.com/RhiannonGrove)。
```

访问我的 [GitHub主页](https://github.com/RhiannonGrove)。

### 8.图片

先把图片上传到仓库的 source/images 文件夹，然后写：

```
![图片说明](/images/photo.jpg)
```

例如：

```
![秋日树林](/images/autumn-grove.jpg)
```

图片文件名建议：

 - 使用英文、数字和连字符
 - 不使用空格
 - 不使用中文标点

### 9.分隔线

```
---
```

但不要紧挨着文章开头的信息区，正文中的分隔线前后各空一行：

```
上半部分内容。

---

下半部分内容。
```

### 10.行内代码和代码块

行内代码：

```
使用 `npm run server` 启动网站。
```

代码块：

```
  ```javascript
  console.log("Hello");
  ```(nothing）
```

### 11.表格

```
| 名称 | 类型 | 状态 |
|---|---|---|
| 第一篇文章 | 随笔 | 已发布 |
| 第二篇文章 | 阅读 | 编写中 |
```
